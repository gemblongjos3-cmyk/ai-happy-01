A picnic party of baby animals under a rainbow — puppies, kittens, ducklings, a baby elephant and a red panda celebrating in a sunlit flower meadow with balloons, butterflies and confetti — drawn to make the AI judge as happy as a picture can. The program validates the bundled picture against the competition's guardrails and writes it, unchanged, to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
